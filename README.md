# ⚡ Crypto Monitor & Report

Небольшой десктопный pet-проект на Python для мониторинга криптовалютного рынка, созданный для **практики вайбкодинга (Vibe Coding)** — разработки в связке с ИИ-агентом через архитектурные правила (`AGENTS.md`) и кастомные скиллы (`.agents/skills/`).

Приложение работает **полностью автономно** без серверов, СУБД и тяжелых аналитических библиотек (`pandas`, `numpy`), мгновенно запускается и упаковывается в единый `.exe` файл.

---

## 🎯 Идея и подход (Vibe Coding)

Проект спроектирован вокруг принципов управляемой агентной разработки:
- **[`AGENTS.md`](./AGENTS.md)** задает жесткие архитектурные рамки проекта: технологический стек, запрет на тяжелые библиотеки и внешние БД, формат логирования ошибок (`[PARSER ERROR]`) и совместимость с `PyInstaller`.
- **[`.agents/skills/crypto-parser/SKILL.md`](./.agents/skills/crypto-parser/SKILL.md)** обучает агента правилам очистки RSS-лент от HTML-шума, фильтрации рекламного спама и точной категоризации новостей по тикерам монет.

---

## ✨ Основные возможности

- **Живые котировки и свечные графики:**
  - Получение актуальных цен (USD) и суточного изменения (24h %) через публичные API **CoinGecko** и **Binance** (без API-ключей).
  - Отрисовка сглаженных графиков цен за выбранный период напрямую через `Pillow` (в темной теме для превью GUI и в светлой теме для печати в PDF).
- **Умный сбор и фильтрация крипто-новостей:**
  - Параллельный парсинг **CoinDesk**, **Cointelegraph**, **Decrypt** и **Google News RSS** с помощью `feedparser` и `requests`.
  - Фильтрация по монетам (`BTC`, `ETH`, `SOL`, `BNB`, `XRP`, `LINK`) и временным интервалам (`За 1 час`, `За 6 часов`, `За 24 часа`, `За неделю`, `За месяц`).
  - Дедупликация заголовков и очистка от HTML-тегов / рекламного спама на чистых структурах данных Python (`list`, `dict`, `set`).
- **Кликабельные заголовки-ссылки:**
  - Заголовки новостей в окне превью и в итоговом PDF-документе являются активными гиперссылками на первоисточник статьи.
- **Экспорт PDF-рапортов в один клик:**
  - Генерация отчета через `fpdf2` с полной поддержкой кириллицы (UTF-8 TTF), таблицей котировок, графиками цен и списком новостей.
  - Автоматическое сохранение на Рабочий стол с именем выбранных активов (например, `bnb_raport.pdf` или `btc_sol_raport.pdf`).
- **Легковесный JSON-кэш:**
  - Все данные сохраняются во временный файл `temp_data.json`, который полностью перезаписывается при каждом новом запросе.

## 🛠 Технологический стек

| Компонент | Технология |
| :--- | :--- |
| **Язык** | Python 3.10+ |
| **GUI (Интерфейс)** | `CustomTkinter` (Cyber Navy Dark UI) |
| **Сетевые запросы и RSS** | `requests`, `feedparser` |
| **Графики цен** | `Pillow` (`PIL.ImageDraw`, 2x supersampling) |
| **Генерация PDF** | `fpdf2` (Unicode / TTF) |
| **Обработка данных** | Стандартные структуры Python (`list`, `dict`, `set`, `json`, `re`) |
| **Сборка в `.exe`** | `PyInstaller` (`--onefile --windowed`) |

├── main.py                      # Точка входа приложения

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
python main.py
```

### 3. Сборка автономного `.exe` файла
```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --name CryptoMonitor --icon assets/app_icon.ico --add-data "assets;assets" --exclude-module pandas --exclude-module numpy main.py
```
Готовый исполняемый файл появится в `dist/CryptoMonitor.exe`.
